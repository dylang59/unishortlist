# Uni Shortlist

A UK university course finder that helps you explore courses, compare options,
and build a shortlist.

## Features

- Search by subject, university, and location.
- Compare entry requirements and university rankings.
- Save courses and searches, and share your shortlist.
- Explore additional course and student information where available.

## Run locally

With Node.js 18 or later installed:

```sh
npm start
```

Open http://localhost:8787 in your browser. An internet connection is required
for local course searches.

## Built with

JavaScript, HTML, and CSS, with Cloudflare Workers and D1 for the hosted app.

## Course information

An independent project using UCAS course information and other published
education data. It is not affiliated with or endorsed by UCAS or individual
universities. Check official course pages for current details before applying.

Third-party data remains subject to its respective providers' terms.
